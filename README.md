# TCDX Compliance Web

Landing comercial para TCDX Compliance, plataforma SaaS chilena de TECDEX orientada a gestión ISO.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir:

```txt
http://localhost:3000
```

## Build

```bash
npm run build
npm start
```

## Deploy en Vercel

1. Entrar a Vercel.
2. Crear nuevo proyecto.
3. Importar el repositorio `baruj77/webtcdx`.
4. Framework preset: Next.js.
5. Build command: `npm run build`.
6. Output: automático de Next.js.
7. Deploy.

## Nota comercial

La landing mantiene mensajes prudentes sobre IA Auditor:

- No promete certificación automática.
- No reemplaza a una casa certificadora.
- No reemplaza auditores, consultores ni responsables internos.
- IA Auditor se presenta como apoyo bajo validación humana.
